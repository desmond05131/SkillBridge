TIMOTHY - QUIZZES

1. Pull latest main. Follow README.md and import database/course_content.sql.
2. Sign in as Admin. Open Quizzes > Questions to see the shared examples.
3. To practise authoring, create a course and a draft quiz. Open Questions,
   add four distinct options, choose one correct answer and add an explanation.
4. Publish the quiz in Edit. Sign in as a Member, enrol in that course,
   then open My Courses > quiz. Submit answers and check the score and history.

FILES
Frontend/Pages/Timothy/: page appearance.
Backend/Pages/Timothy/: page handlers and input checks.
Backend/Timothy/Quizzes/QuestionStore.cs: question/option SQL.
Backend/Timothy/Quizzes/QuizAttemptStore.cs: attempts, scoring and saved answers.
Backend/Timothy/Quizzes/MySqlQuizReader.cs: quiz/course queries.

Start = overview/history; Quiz = answer form; Review = saved result.
Use website links, never the .cshtml file path.
Login uses cookie claims. The database connection name is SkillBridge.

Questions are editable only while the quiz is a draft with no attempts.
Once an attempt exists, assessment content stays locked to protect saved results.
Answers save on Submit. There is no timer or separate history page.
