STEPS
1. Get the latest main branch and create your own branch. Follow README.md
   to run the website and create a local Admin account.
2. Open your Figma board using the link in README.md. Start with the files
   already in your folder, then add the remaining pages on your board.
3. Reuse the layout, CSS and login. Use one form for Create/Edit.
   Our scope has no separate mobile pages, quiz timer or account closure.
4. Connect your pages to MySQL using parameterised SQL. Check input and
   permissions in C#. Coordinate shared files and SQL changes with Jian Yi.
5. Run dotnet build. Test saving, editing, deleting, invalid input and access
   as a visitor, Member and Admin. Check links between everyone's pages.
6. Commit your source changes and open a pull request for Jian Yi to review.
   Keep screenshots and SQL explanations for your report and presentation.

Before submission, we still need finished features, real learning content,
shared demo data, combined testing, the final report and the presentation.
Keep passwords, bin/, obj/, editor files and helper scripts out of commits.
